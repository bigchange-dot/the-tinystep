User Guide (사용 가이드)

원하는 문장을 “자연스러운 영어”로 만들려면, 아래 팁대로 입력하면 결과가 더 좋아집니다.

1) 목적을 한 줄로 먼저 적기

예시

  • 견적 요청 메일, 정중한 톤
  • 회의 일정 변경 요청, 부드럽게
  • 상대가 상사, 격식 있게

2) 핵심 정보 3가지 포함

  • 무엇을: 요청/문의/공유/사과/리마인드
  • 언제: 기한/시간/일정
  • 관계: 고객/상사/동료(톤 조절에 중요)

3) 문장이 길면 나눠서 입력

긴 문단을 한 번에 넣기보다 문장/문단 단위로 나눠서 교정하면 정확도가 좋아집니다.

4) 추천 입력 템플릿

Template A (요청)
(상황) 때문에 (요청)을 하고 싶습니다. (기한)까지 가능할까요? 톤은 (정중/친근/격식)

Template B (리마인드)
지난번 메일/메시지 관련해서 확인 부탁드립니다. 진행 상황 공유 가능하실까요?

Template C (사과 + 대안)
답변이 늦어 죄송합니다. 대신 (대안/다음 일정)을 제안드립니다.

5) 안전하게 사용하기

  • 개인정보(전화번호/주소/계좌/주민번호)나 회사 기밀을 입력하지 마세요.
  • 결과는 참고용이며 최종 사용 책임은 사용자에게 있습니다.
  • 법률/의료/재무 문서는 전문가 검토를 권장합니다.
